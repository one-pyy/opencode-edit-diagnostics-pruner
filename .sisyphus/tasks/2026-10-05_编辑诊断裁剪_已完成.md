## 目标与来源

独立 Node ESM 插件只裁剪本次编辑文件之外的诊断；Bun 历史 CLI 默认 preview，显式 apply，先完整在线备份，单事务同步 part/event 完成副本。有效契约见 [contract](../docs/contract.md)。

## 范围与执行

真实会话、真实数据库及既有副本不作为测试输入。自动化测试仅使用人工构造的数据库。

1. 共享过滤、插件接线 → verify: 合成路径与 output/metadata 保留断言。
2. 历史 CLI 与备份 → verify: 合成 WAL 数据库、完整恢复、事件重放、并发与回滚测试。
3. 文档与交付检查 → verify: bun test test/、npm run check、实际新增文件内容与链接检查。
